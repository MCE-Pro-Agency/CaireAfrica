# Images et vidéos

Déposez ici les médias du Chef Kara. Tant qu'un fichier est absent, le site
affiche un bloc de remplacement avec la légende : rien ne casse.

| Fichier                      | Utilisé par                          | Format conseillé        |
| ---------------------------- | ------------------------------------ | ----------------------- |
| `hero.jpg`                   | Accueil — bandeau principal          | 2400 × 1350, < 400 Ko   |
| `hero.mp4` (optionnel)       | Accueil — vidéo de fond              | 1080p, < 6 Mo, muet     |
| `og.jpg`                     | Partage réseaux sociaux              | 1200 × 630              |
| `chef/portrait.jpg`          | Accueil + page Le chef               | 1200 × 1500             |
| `prestations/hero.jpg`       | Page Prestations — bandeau           | 2400 × 1350             |
| `prestations/domicile.jpg`   | Chapitre 01                          | 1600 × 1200             |
| `prestations/evenements.jpg` | Chapitre 02                          | 1600 × 1200             |
| `prestations/partout.jpg`    | Chapitre 03                          | 1600 × 1200             |
| `contact/table.jpg`          | Page Contact — colonne gauche        | 1200 × 1800             |
| `home/carte.jpg`             | Accueil — lien « Voir la carte »     | 1200 × 900              |
| `home/prestations.jpg`       | Accueil — lien « Les prestations »   | 1200 × 900              |
| `home/galerie.jpg`           | Accueil — lien « La galerie »        | 1200 × 900              |
| `galerie/01.jpg` … `27.jpg`  | Galerie (voir `src/data/gallery.js`) | 1400 px de large        |
| `galerie/06.mp4`, `13.mp4`, `20.mp4`, `24.mp4` | Vidéos de la galerie | 1080p, < 8 Mo           |

Les chemins sont centralisés dans `src/data/` : pour renommer un fichier,
modifiez uniquement la donnée correspondante.
